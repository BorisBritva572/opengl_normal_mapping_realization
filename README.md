# Normal Mapping (OpenGL)
В этом репозитории содержится программная реализация метода рельефного текстурирования Normal Mapping.

# Управление
| клавиши| функционал |
| :--- | :--- |
| W/A/S/D | перемещение вперед/влево/вправо/назад |
| shift/space | перемещение вниз/вверх |
| Мышь | Поворот камеры |

# Требования
* **Visual Studio 2019/2022**
* **GLFW 3.x**
* **GLEW**
* **GLM**
